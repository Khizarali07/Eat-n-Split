# Eat-n-split (Course project)

A small bill-splitting / expense sharing demo built during the Jonas Schmedtmann course. The app demonstrates form handling, controlled components and simple state updates in React.

## Key features

- Add expenses with amount and payer
- Split calculations and per-person totals
- Edit/remove entries (local state)
- Clean, responsive UI

## Tech

- React (Create React App)
- CSS for styling

## Run locally

1. Install dependencies: `npm install`
2. Start dev server: `npm start`
3. Build for production: `npm run build`

## Notes

- Data is stored in local component state for demonstration.
- To add persistence, you can wire in localStorage or a small backend API.
